engineering each have a support reviewer. The team uses up to four simultaneous
executions and rotates review/documentation roles as specialists finish.

## Working cycle

1. Read STATUS, this runbook, the current Notion notebook, and relevant decisions.
2. Inspect checkout, permissions, runtime, and the last evidence bundle.
3. Select a task with owner, source requirement, acceptance, dependency, and file scope.
4. Agree on shared contracts; give each file a single writer.
5. Implement and run meaningful positive/negative checks.
6. Have a different agent review critical changes and their evidence.
7. Integrate, record observed results/limits, and leave a next action.

## Handoff

Record task/owner/reviewer, commit and dirty state, changes, commands, expected and
observed results, artifact paths, untested limits, blocker, and next action.
Tag claims as static inspection, reproduced, reported by a source, inference,
proposal, or pending. Historical PASS records retain their original date and scope.

## Support and feedback

Every support reviewer prepares context, tracks blockers, and checks documentation
against evidence. Acknowledge specific work: a verified source, isolated fault,
useful acceptance criterion, or reproducible run. Give a concrete next step and
help resolve ambiguity. Respectful encouragement accompanies independent review.

## Daily research

The hosted daily worker is active at 09:00 America/New_York. Read the live
[research journal](https://chatgpt.com/space/page_1b30d8095d408191b8d36f8483159475)
and its automation registry before changing schedules. The native controller
supervises state hourly; substantive literature research belongs to the daily
worker. Future runs must verify their own source access and record limitations.

Each research entry keeps source/version/date, content read, supported finding,
limits, changed assumption, affected task, and next action. Deduplicate sources;
record no relevant changes when appropriate. Proposed research does not silently
change an experimental protocol.
